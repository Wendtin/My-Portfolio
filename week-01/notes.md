## Overview

Week 01 introduced the foundational skills of Linux system navigation,
file permission management, and basic threat detection scripting. Sessions
focused on understanding the Linux filesystem hierarchy, manipulating files
and directories from the command line, and producing a hardening script
as a deliverable artifact.

## Tools Used

| Tool | Purpose |
|------|---------|
| bash | Command-line scripting and system navigation |
| chmod/chown | File permission management |
| grep | Pattern matching and log analysis |
| nano | Text file editing |
| git | Version control and portfolio submission |

## Key Concepts

- Linux filesystem hierarchy (/, /etc, /var, /home, /tmp)
- File permissions: read, write, execute for owner/group/other
- Threat IP identification and basic hardening
- Shell scripting fundamentals

## Artifacts

- `discovery.txt` — system discovery output
- `harden.sh` — hardening script produced during session
- `results.txt` — audit results
- `threat_ips.txt` — identified threat IP addresses

## Challenges

Adapting to the Linux command-line environment after limited prior
exposure required deliberate practice. Navigating permission structures
and understanding the difference between user and root contexts presented
an initial learning curve that was resolved through hands-on repetition.
