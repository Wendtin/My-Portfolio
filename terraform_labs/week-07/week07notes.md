## Overview

Week 07 introduced offensive reconnaissance techniques and structured
vulnerability analysis. Sessions covered active and passive
reconnaissance using Nmap and OSINT tools, threat actor profiling,
perimeter assessment methodology, and remediation planning. All
techniques were applied in a legal, lab-controlled environment.

## Tools Used

| Tool | Purpose |
|------|---------|
| Nmap | Active network scanning and service enumeration |
| OSINT frameworks | Passive reconnaissance and target profiling |
| Metasploit (install) | Exploitation framework setup |
| nano | Report authoring |
| git | Version control and portfolio submission |

## Key Concepts

- Active vs. passive reconnaissance methodology
- Nmap scan types: SYN, version, OS detection, script scans
- OSINT threat actor profiling techniques
- Vulnerability identification and CVSS scoring
- Perimeter assessment and attack surface mapping
- Remediation planning and prioritization

## Challenges

Interpreting Nmap output and accurately mapping open ports to
exploitable services required practice. Distinguishing meaningful
reconnaissance data from noise in OSINT results was a recurring
challenge that improved with structured profiling methodology across
multiple sessions.
