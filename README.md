#Enterprise Multi-Site Network Lab Situation (Cisco Packet Tracer)

## Project Overview 
This Multi-sites network Lab is a simulation designed to bridge the gap between theoritical knowledge and real-world application. It allows us to build, configure, and troubleshoot complex, geographically dispersed infrastructures. Basically, the core purpose of this lab or project is to simulate a "production-ready" environment, ensuring high availability, scalability, and security accross multiple locations.

**Project composition**
 - Headquarter: The main office installation (MO: for Main Office)
 - Branch Offices (BO)
 - Internet Service Provider (ISP) for the Internet simulation 
 - Security segmentation between departments

This lab demonstrates advanced networking concepts such as VLAN (Virtual Local Area Network), inter-VLAN routing. 
The project was built using Cisco Packet Tracer on Kali Linux
